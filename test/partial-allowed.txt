# The uses of a partial or an unchecked function in what `Runtime.Interpreter.step` can reach,
# each with why it raises no exception and reads nothing outside an array.
# `scripts/step-inventory.py` takes the list from GHC's Core and fails, in the gate, if a use
# is not here, or is here and no longer found. A line is
#
#   Module.definition | the function | the reason
#
# and `*` for the definition allows the function everywhere. No definition that a step reaches
# calls `error`, `undefined`, `head`, `tail`, `fromJust`, `!!`, an indexing that checks and
# raises (`!`), `toEnum`, `throw`, or an unsafe coercion: the script looks for these too.
#
# What WebAssembly prescribes a trap for is a `Left` of the step and no exception: division by
# zero and the overflow of signed division (`Runtime.Numeric.intDiv32`, `intDiv64`, `intRem32`,
# `intRem64`, listed below), a conversion of a float that is no number or out of range
# (`Runtime.Convert.truncToI32`, `truncToI64`, which compare before they convert), and an
# access outside a memory or a table (`Runtime.MemInst.loadChecked` and `storeWordAt`,
# `Runtime.TableInst.getEntry` and the others, which compare with the size and answer through a
# `Maybe` or a continuation for the failure).
